DigitRell TMS · Design system v1

Calm teal, warm amber, plenty of white

A cool deep teal says “reliable and in control”. Amber is kept for the one thing that needs you. Every colour pair below passes WCAG AA (4.5:1 for text), and status is always shown with a word and a dot, never colour alone.

Minimum body size 14 px, never below 12 px. Amounts use tabular figures (font-variant-numeric: tabular-nums) and Indian grouping (₹1,00,000).

Buttons

One primary action per area

  • Height 44 px (36 px inside table rows). Radius 10 px.
  • Labels are verbs with the object: “Award to Kaveri · ₹42,500”, not “Submit”.
  • Order: primary, secondary, destructive. Destructive never sits first.

Inputs

Label on top, help below

Searchable, saved addresses first
Focus: 2 px teal ring
Enter the weight in tonnes, e.g. 14.
Read-only: set in Policies

Required fields carry an amber asterisk; optional ones say “(optional)”. Errors appear on blur or submit, next to the field, and keep what was typed.

Status

Every trip status has one chip

Request received Booked Quotes requested Quotes received Awarded Sourcing truck Truck confirmed Cleared Ready for pickup In transit Delivered POD received Invoiced Closed On hold Cancelled

Five tones only: grey = waiting on others, amber = waiting on you, blue = moving, green = done, red = blocked; purple marks money states. The detail page also shows a 7-stage progress bar so users never read 16 raw statuses.
